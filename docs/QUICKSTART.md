# Quick Start Guide

Panduan cepat untuk memulai dengan proyek Mitra & Kerjasama.

## 🚀 5 Menit Setup

### 1. Clone Repositori

```bash
git clone https://github.com/guruips/mitra.git
cd mitra
```

### 2. Install Dependencies (jika diperlukan)

```bash
npm install
# atau jika menggunakan yarn
yarn install
```

### 3. Setup Environment

```bash
# Copy file environment template
cp .env.example .env

# Edit .env sesuai konfigurasi Anda
```

### 4. Start Development Server

```bash
npm run dev
# atau
yarn dev
```

### 5. Buka di Browser

```
http://localhost:3000
```
