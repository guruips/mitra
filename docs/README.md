## 🎯 Kontribusi pada Dokumentasi

Jika Anda ingin berkontribusi pada dokumentasi:

1. Fork repositori
2. Buat branch: `git checkout -b docs/nama-dokumentasi`
3. Edit atau tambah dokumentasi
4. Commit: `git commit -m "docs: Improve XYZ documentation"`
5. Push: `git push origin docs/nama-dokumentasi`
6. Buat Pull Request
