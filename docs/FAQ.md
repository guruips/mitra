# Frequently Asked Questions (FAQ)

## 🤔 Pertanyaan Umum

### Bagaimana cara memulai berkontribusi?

Lihat [CONTRIBUTING.md](../CONTRIBUTING.md) untuk panduan lengkap.

**Ringkas:**
1. Fork repositori
2. Buat branch baru
3. Buat perubahan
4. Commit dengan pesan yang jelas
5. Push dan buat Pull Request

### Apa saja tipe kontribusi yang diterima?

- Materi pembelajaran (konten IPS)
- Bug reports dan fixes
- Fitur baru dan improvements
- Dokumentasi
- Desain dan grafis
- Riset dan data

### Bagaimana cara melaporkan bug?

1. Buka [GitHub Issues](https://github.com/guruips/mitra/issues)
2. Klik "New Issue"
3. Pilih template "Bug Report"
4. Isi detail bug dengan jelas
5. Submit

### Bagaimana cara mengajukan fitur baru?

1. Buka [GitHub Issues](https://github.com/guruips/mitra/issues)
2. Klik "New Issue"
3. Pilih template "Feature Request"
4. Jelaskan fitur yang diusulkan
5. Submit untuk diskusi dengan tim

### Berapa lama proses review PR?

Biasanya 2-7 hari tergantung kompleksitas dan workload tim.

### Apakah ada kompensasi untuk kontributor?

Untuk saat ini, kontribusi adalah sukarela. Namun kami memberikan:
- Recognition di contributor list
- Certificate of contribution
- Akses eksklusif ke resources komunitas
- Kesempatan networking

Untuk partnership atau sponsorship khusus, hubungi contact@catatangurulps.com

### Bisakah saya menggunakan konten proyek ini?

Ya! Proyek ini menggunakan MIT License. Anda bisa menggunakan, memodifikasi, dan mendistribusikan, dengan syarat:
- Sertakan license dan copyright notice
- Tidak ada garansi

Lihat [LICENSE](../LICENSE) untuk detail lengkap.
